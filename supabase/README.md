# supabase: local database

The local Supabase stack (`./sellekni up` starts it): Postgres on `127.0.0.1:54322`, Studio on `http://127.0.0.1:54323`.

| Path | What |
|---|---|
| `migrations/` | Schema (`…_init.sql`): profiles, hospitals and statuses, incidents, reports, assessments (every recompute), pre-alerts, audit events, ETA cache, SMS outbox, then band override, crew updates, hospital-scoped access |
| `seed.sql` | Generated by `pnpm db:seed-sql` from `data/`. Don't edit it by hand |
| `config.toml` | Local stack config |

`pnpm db:reset` regenerates the seed and resets the database. `./sellekni reset` only empties the demo data.
Architecture and row-level security are covered in [docs/04](../docs/04-ARCHITECTURE-AND-STACK.md).
