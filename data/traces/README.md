# Replay traces (SYNTHETIC)

Generated by `pnpm --filter mobile traces` (`apps/mobile/scripts/make-traces.ts`, deterministic: seeded noise).
These are **not recordings of real crashes**: they are plausible shapes built to exercise the detector rules
(docs/04 §3.2). Replace or complement them with sensor-lab recordings (M9) to tune the thresholds.

Format (one header line, one row per sample, 50 Hz, GPS speed at 1 Hz sample-and-hold):

| column | unit |
|---|---|
| `t` | ms since the start of the trace |
| `ax ay az` | acceleration in g, gravity included (phone frame) |
| `gx gy gz` | angular rate in rad/s |
| `speed` | latest GPS speed in km/h, empty = no fix |

| trace | scenario | expected |
|---|---|---|
| `rollover_71` | 71 km/h, 5.5 g side impact, one roll, stopped on the roof | alert (rule c) |
| `frontal_45` | 45 km/h, 12 g frontal impact, stopped in 1.2 s | alert (rule b) |
| `speed_bump` | 50 → 32 km/h, two sharp bumps (one > 4 g for ~20 ms) | no alert |
| `hard_brake` | 90 → 0 km/h at 0.9 g | no alert |
| `phone_drop` | phone falls out of its holder at 60 km/h, the car drives on | no alert (candidate, rejected: not stopped) |
| `walking` | 60 s walking at 5 km/h, phone dropped on the pavement, no GPS for 4 s | no alert (never arms) |

Do not hand-edit a CSV: `apps/mobile/test/detector.test.ts` fails if a file differs from the generator.
